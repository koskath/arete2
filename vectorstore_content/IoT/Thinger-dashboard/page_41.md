This widget can be shown in different appearances, which can be specified in the **Switch Style** menu:

option **Switch**: [x] is the standard configuration with a little horizontal switch
option **Button**: [x], which is an improved face that can be configured with different colors and icons
option **Push button**: [x] it configurates the button to be automatically switched off when it is not being clicked. This option is perfect to implement the toggle switches behavior on the devices.
