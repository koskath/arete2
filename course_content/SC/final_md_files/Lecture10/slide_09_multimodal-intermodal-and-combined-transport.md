# Multimodal, Intermodal and Combined Transport

|                                     |                            |                           |
|-------------------------------------|----------------------------|---------------------------|
| **Containerised Multimodal Transport**  | Pre-Carriage               | Onward Carriage           |
|                                     | Main Haul by By Sea, Inland Navigation or Railway |                           |
| **Accompanied Intermodal Transport**    | Pre-Carriage               | Onward Carriage           |
|                                     | Ro/Ro-Ferry or Rolling Road|                           |
| **Un-Accompanied Intermodal Transport** | Pre-Carriage               | Onward Carriage           |
|                                     | Ro/Ro-Ferry or Piggy-Back  |                           |
| **Airfreight Operations**             | Pre-Carriage               | Onward Carriage           |
|                                     | Air freight or Trucking    |                           |

Source: Kummer and Schramm (2004)
